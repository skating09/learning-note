一、PolySpace静态扫描工程配置

polyspace简介
Polyspace是由MathWorks开发的一种软件验证工具。它旨在检测和消除C和C++编写的嵌入式软件中的运行时错误，如整数溢出、除以零和缓冲区溢出。Polyspace使用静态代码分析技术来分析源代码，并在软件执行之前识别潜在错误。它提供了一个图形界面来查看和分析分析结果，使开发人员能够快速识别和修复潜在错误。Polyspace在安全关键行业，如汽车、航空航天和医疗设备中得到了广泛应用，在这些行业中，软件可靠性至关重要

二、Polyspace 常犯错误汇总

1.溢出(Overflow)

例子：
DMA_u16TxData[2] = (uint16_t)u8AutoChnSel << 8; DMA_u16TxData[0] =(uint16_t) (0x80 | (ExtAdc_u8Ads7038TxId << 3)) << 8; DMA_u16TxData[0] = (uint16_t)(0x80 | (ExtAdc_u8Ads7038TxId << 3)) << 8; DMA_u16TxData[0] = (uint16_t)(0x80 | (ExtAdc_u8Ads7038TxId << 3)) << 8; Uint8数据，向左移位八位并分配给Uint16数据，存在溢出风险。
这里面报了很多溢出的警告，但绝大多数都是数据类型不匹配相互赋值，或者是不匹配的数据类型进行做与或等操作。经评估没有风险不会导致溢出。

2. 未初始化变量(Non-initialized variable)

boolean_t Boost_bInputZeroLoss;
Calibra_vidAcSampleValAvg(PFCCtrl_u16LineSumCnt,Boost_bInputZeroLoss);
在定义变量后需要初始化变量。

3. 数组索引越界(Out of bounds array index)

例子：
MailBox_Msg CanApp_aMB_Infor[CanApp_ID_IND_MAX]; CanApp_ID_IND_MAX 16
CanApp_aMB_Infor[u32Rx_Tx_MB].MB_flags.bits.u16BfMB_Enable = 0;
u32Rx_Tx_MB的范围为0~32，导致该值没得到适当保护。

4.除以零(Division by zero)

uint16_t PFCCtrl_u16LineSumCnt = 0u;
PFCCtrl_u16LineSumCnt = PFCCtrl_u16LineSumCntTemp;
……
Boost_u16LineVoltRmsQ5 = Control_u16SqrtRoot(PFCCtrl_u64RLineVoltSum/PFCCtrl_u16LineSumCnt);
当然这里没有问题，在中断中计算后再赋值给PFCCtrl_u16LineSumCnt，再去启动过零任务计算这个除法，没有风险。

5. 非法取消引用的指针(Illegally dereferenced pointer)

例子：
uint16_t s16SoftwareStringCopy(char_t const* pchSource, char_t* pchDestination, uint16_t u16SourceLength, uint16_t
u16Destistatic uint16_t CanCB_u16CanReadWord(uint16_t const pchSource[2])
{
uint16_t u16Value = pchSource[0] + (pchSource[1] << 8);
return u16Value;
}
这里是没问题的，属于一种常规数据处理方法。

  1. Number of return points shall not greater than 1;
  2. Max nesting level shall not greater than 4;
  3. Local function identifier name shall not exceed 31 characters;
  4. Identifier name should be between 3 and 31 characters;
  5. The first character for Global function ‘initECAN’ must be an upper-case letter;
  6. In Global function descriptive body shall follow upper camel case (2 conseccutive capital letters are not allowed);
  7. The first character for Global function must be an upper-case letter;
  8. Structure typename ‘tstrSupervisedEntity’ should start with a upper case letter;
  9. In Type Field and Descriptive Body for global function ‘Database_u32GetBat3_1Voltage’ the underscores are forbidden.
